# SentinelCart

SentinelCart is a simple e-commerce application built to demonstrate an end-to-end DevSecOps and cloud-native deployment workflow.

## Project Goals

- Build and containerize a web application
- Implement CI using GitHub Actions
- Scan dependencies and container images for vulnerabilities
- Provision AWS infrastructure using Terraform
- Deploy the application to Amazon EKS
- Store container images in Amazon ECR
- Implement GitOps using Argo CD
- Enforce Kubernetes security policies using Kyverno
- Detect runtime threats using Falco
- Monitor application and cluster health using Prometheus and Grafana
- Manage secrets securely

## Planned Technology Stack
